# ChatServer
基于muduo实现 可以工作在nginx tcp负载均衡环境中的集群聊天服务器与客户端源码

 实现功能
- ✅ 用户注册、登录、注销，
- ✅ 一对一私聊消息
- ✅ 离线消息存储，用户上线自动推送离线消息
- ✅ 添加好友，查看好友列表
- ✅ 创建群组、加入群组
- ✅ 群聊消息广播
- ✅ 客户端命令行交互，支持 help 查看全部指令
- ✅ 支持 Nginx‑TCP 负载均衡，多服务节点集群部署

- 编译方式
- cd build
- rm -rf *
- cmake ..
- make
- 编译完成后 bin目录产出两个可执行程序：
- ChatServer`：聊天服务端
- ChatClient`：聊天客户端
